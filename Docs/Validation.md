# 测试复现与验证边界

验证分为工具行为测试、匹配客户端原始加载指令对照和真实游戏进程验收。前两类结果不能替代游戏中的包发现、全局资源寻址或界面效果结论。

## 源码测试

在仓库根目录构建并运行：

```powershell
.\Tools\Build.ps1 -Configuration Debug
.\Tools\Build.ps1 -Configuration Release
.\Artifacts\Bin\x64\Debug\PKNPacker.Tests.exe
.\Artifacts\Bin\x64\Release\PKNPacker.Tests.exe
```

固定测试向量来自已确认的原始密码流指令对合成输入的结果，运行时无需客户端或 IDA。其来源指纹保存在 `Tests/PKNPacker.Tests/Fixtures/SnowVectors.json`，不包含客户端可执行文件。

核心测试覆盖：

- 密码流初始状态、跨块流状态和有符号密钥字节处理。
- 五种存储模式，空／短／1024 字节前缀／64 KiB 跨块内容。
- UTF-16 路径、新建、变长替换、显式删除、新增、撤销和改名生成。
- 工作区完整／部分解包续传、待提交操作保护、缺失文件和清单身份检查。
- 截断、校验、计数、偏移、未知格式、压缩正文损坏及不安全路径。
- 输出占用、取消、临时文件清理，以及独立批量任务失败后继续。

每次运行在 `Artifacts/TestRuns/<进程 ID>/TestReport.json` 记录通过、失败、跳过和样本结果。部分 Windows 权限配置不允许创建用于测试的符号链接，该场景会明确记为跳过；应检查报告中的逐项结果。

2026-10-12 源码发布整理时，从独立的待发布源码目录重新构建四个项目，Debug／Release 均为 0 警告、0 错误。该目录未包含客户端样本，两种配置的合成测试各 136 通过、0 失败，符号链接场景因 Windows 1314 各跳过 1 项；样本回归按无输入记录为跳过。部署脚本生成的 ZIP 与 42 项文件清单及 SHA-256 一致，包含项目许可证。

## 可选的原包回归

自行提供匹配版本的完整 `Packs` 目录：

```powershell
.\Artifacts\Bin\x64\Release\PKNPacker.Tests.exe --samples 'D:\Game\Packs' --all
.\Artifacts\Bin\x64\Release\PKNPacker.Cli.exe verify 'D:\Game\Packs' --report .\OriginalVerify.json
```

`--all` 对指定目录中的全部 PKN 进行完整解码检查。样本测试还使用 `Shader_00000.pkn` 执行解包、重封、改名和缺失文件检查；未带 `--all` 时使用代码中列出的六个代表性包。任意单独样本的读取检查可直接使用 CLI `verify`。

该过程只读取原包，输出放在项目生成目录。仓库不提供原始客户端、资源包、解包内容或开发机器上的原始分析报告。

## 尚未完成的验收

真实游戏进程中的包发现、全局资源路径寻址和可达界面修改效果尚未实测。新增资源通过索引与解码函数的解析／读取对照，游戏实际引用仍需单独验收。大厅和地图环境亦不在当前工具验证结论中。

独立无开发环境机器的分发启动、真实磁盘耗尽场景，以及其它客户端版本或 PKN 变体也尚未验证。报告中的跳过项与上述边界均不应记为已通过。
